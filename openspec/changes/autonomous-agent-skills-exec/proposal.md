# Proposal: Autonomous Agent Harness, Skills & Universal Exec Tool

## 1. Overview & Objectives
Трансформация Telegram-шлюза из одноразового stateless-бота в полноценного **автономного агента**, способного:
1. Выполнять реальные системные действия в ОС/контейнере через универсальный инструмент **`exec`** (cURL, CLI, терминал).
2. Поддерживать долговременную непрерывную память диалога (**Long Context**) в SQLite (`data/chat_history.db`) с возможностью сброса и архивации через команду **`/new`**.
3. Загружать и исполнять специализированные сценарии и регламенты (**Skills**) из `skills/<skill_name>/SKILL.md`.
4. Работать в циклическом харнессе (ReAct Loop) с надежной защитой от зацикливания (Anti-Looping) до 8 шагов с принудительным синтезом ответа.

## 3. Нефункциональные требования (NFR)
1. **Безопасность инструмента `exec`**:
   - Таймаут исполнения: максимум 30 секунд.
   - Ограничение размера вывода: максимум 4096 символов (усечение с сообщением), чтобы вывод команд не переполнял контекстное окно LLM.
2. **Персистентность памяти**:
   - База SQLite в режиме WAL (`PRAGMA journal_mode=WAL;`).
   - Изоляция сессий пользователей по `session_id`.
   - `/new` архивирует текущую сессию и генерирует новый `session_id`, сбрасывая контекст.
3. **Отказоустойчивость цикла**:
   - При превышении 8 шагов модель не падает с ошибкой, а получает системный запрос на синтез собранных наблюдений.
